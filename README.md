# In-Context Flow Matching

Code for [*Support-Conditioned Flow Matching Is Kernel Smoothing*](https://arxiv.org/abs/2605.13386). Reproduces all figures and numerical verification of theorems in the paper.

## Abstract
Generative models are often conditioned on a small set of examples via cross-attention. Under the Gaussian optimal-transport path, we show that the exact velocity field induced by a finite support set is a Nadaraya--Watson kernel smoother whose bandwidth decreases with flow time, from broad averaging at early steps to nearest-neighbor at late steps. A single Gaussian-kernel attention head exactly computes this field, connecting cross-attention conditioning to classical kernel theory. The theory predicts three failure regimes: nearest-neighbor collapse of the kernel at high dimension, mismatch between the isotropic kernel and the data geometry, and insufficient support for nonparametric estimation. Experiments on Gaussian mixtures, spherical shells, and DINOv2 ImageNet features confirm that learned conditioning improves in precisely these regimes, and that IP-Adapter's cross-attention implements approximate NW smoothing in practice.


## Setup

```bash
uv sync
```

`pip install -r requirements.txt` also works. Python >=3.11 required; pinned dependencies in `uv.lock`.

Seeds are set per config (`seed: 42`) and overridable via `--override seed=N`. W&B logging is optional -- set `WANDB_MODE=disabled` to skip. ImageNet experiments need `HF_TOKEN` for the HuggingFace download; everything else runs on synthetic data with no setup.

## Training

Each experiment has a standalone YAML config in `configs/`. Train with:

```bash
uv run python train.py --config configs/b1_main_r2.yaml --override seed=42
```

Evaluate a checkpoint:

```bash
uv run python evaluate.py --config configs/b1_main_r2.yaml \
    --checkpoint checkpoints/b1_main_r2_s42/best.pt
```

For ImageNet latent experiments, encode DINOv2+PCA features first:

```bash
export HF_TOKEN=<your-token>
uv run python scripts/encode_imagenet_dino.py
uv run python train.py --config configs/imagenet_off.yaml --override seed=42
```

## Reproducing figures

Plot scripts read from `results/metrics/` (generated by evaluation, or shipped with `--include-results`):

```bash
uv run python scripts/plot_fig1_transition.py
uv run python scripts/plot_fig2_combined.py
uv run python scripts/plot_fig3_ipadapter.py
uv run python scripts/plot_fig3_scarcity.py
uv run python scripts/plot_fig9_samples.py
uv run python scripts/plot_appendix_combined.py
```

Theorem verification runs on CPU in under a minute:

```bash
uv run python scripts/verify_theorems.py
```

## Compute

Everything was trained on RTX 4090s. A single R^2 run (100k steps) takes ~1 hour on any modern GPU. The full suite across all configs and seeds was ~350 GPU-hours. Theorem verification is CPU-only and takes under a minute.
